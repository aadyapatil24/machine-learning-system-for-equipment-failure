# 🏭 AI Smart Predictive Maintenance System

An Industry 4.0 inspired predictive maintenance application that predicts machine failures using Machine Learning and provides maintenance recommendations through an interactive SCADA-style dashboard.

## Features

✅ Machine Failure Prediction

✅ Health Score

✅ Failure Probability

✅ Interactive Analytics Dashboard

✅ Prediction History

✅ Industrial SCADA Inspired UI

## Tech Stack

- Python
- Streamlit
- Scikit-Learn
- Random Forest
- Plotly
- Pandas

## Dataset

AI4I 2020 Predictive Maintenance Dataset

## Machine Learning Model

Random Forest Classifier

Accuracy: 98.4%
